# TAINA Knowledge Map V1 — расходы и варианты запуска

Документ описывает текущую архитектуру V1, а не обещает стоимость будущих функций.

## Короткий ответ

Для локального запуска и тестирования обязательных покупок нет. Node.js, React, Vite, TypeScript и IndexedDB не требуют платной лицензии. В текущей версии нет backend, облачной базы, регистрации, AI API или платной синхронизации.

## Три способа пользоваться продуктом

### 1. Локальный запуск для разработки и внутреннего тестирования

- Node.js LTS — бесплатно.
- Зависимости проекта — открытые пакеты; установка требует доступа к npm registry.
- Браузер — уже установленный современный браузер.
- Сервер, база данных, AI API, домен — не нужны.
- Обязательные расходы: 0 ₽.

Это самый дешёвый путь, но запуск через npm и терминал неудобен для обычного покупателя. Пользовательские данные остаются в IndexedDB конкретного браузера и устройства.

### 2. Публикация как статического веб-приложения

После успешной production-сборки приложение можно разместить на статическом хостинге.

- Бесплатного тарифа статического хостинга может хватить для раннего пилота; лимиты и условия нужно проверить перед публикацией.
- Собственный домен необязателен: можно начать с адреса хостинга.
- Плановый бюджет на старте: 0 ₽ без собственного домена и платных дополнительных услуг.
- Домен — отдельная необязательная ежегодная покупка; цена зависит от зоны и регистратора.

Важно: статическая публикация не превращает приложение в облачный командный сервис. Данные каждого пользователя по-прежнему хранятся локально в его браузере. Нет аккаунтов, восстановления через сервер, общей базы или синхронизации между устройствами.

### 3. Полноценный облачный продукт для команд — не входит в V1

Для общей базы, аккаунтов, ролей, командного доступа, синхронизации, серверных резервных копий и журнала аудита понадобятся backend, база данных, аутентификация, мониторинг, политика хранения и защиты данных. Это отдельный проект с отдельной оценкой. Не покупать инфраструктуру под него до проверки спроса на V1.

## Что не покупать сейчас

- VPS или выделенный сервер;
- платную базу данных;
- OpenAI/другой AI API ради встроенных функций — в текущей версии его нет;
- платные аккаунты разработчика;
- домен до выбора способа распространения;
- платный хостинг до появления реальной нагрузки или необходимости в функциях, которых нет в бесплатном тарифе.

## Что всё-таки потребуется перед продажей

1. Получить зависимости, закрепить конкретные версии и создать lockfile.
2. Успешно выполнить production build.
3. Пройти E2E-проверки в реальном браузере, включая сохранение, импорт, восстановление и два окна.
4. Проверить заголовки безопасности на выбранном хостинге.
5. Подготовить понятную инструкцию резервного копирования и явно сообщить покупателю, что данные локальны и не синхронизируются.
6. Отдельно выбрать платёжную платформу; её комиссии зависят от страны, способа оплаты и тарифа.

## Бюджетное решение

Для текущего прототипа разумный бюджет на обязательные покупки — **0 ₽**. Если понадобится публичный адрес, сначала проверить бесплатный статический хостинг, а домен покупать только после решения о брендовом адресе. Не заказывать сервер и облачную базу, пока продукт остаётся local-first.
